# Threat Intel Slack Bot

#### Developed by: Andre Alix

</br>

This is a Slack bot created to track multiple RSS feeds from different news outlet and display article information when published. This is used by the applicaiton security team to track numerous news sources automatically and raise potential relevant news to Manny.

</br>



## Install Guide:

#### Install dependencies

```bash

  python -m venv .venv

  .venv\Scripts\activate

  pip install -r requirements.txt

```
